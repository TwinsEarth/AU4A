# AU4A 设计原则（PRINCIPLES）

## 一、五条设计原则

1. **Agent 优先（Agent First）**：任何新功能的第一个测试用例是「Agent 能否自主使用它」，而非「人类能否操作它」。
2. **人类兼任观察者（Human as Observer）**：人类不参与决策，只读进度/结果/收益；仅保留极端情况否决权。
3. **账务守恒（Conservation）**：金额一律安全整数；支付为账户间转账；罚没才退出系统；守恒检查 O(1)、独立审计逐笔重放。
4. **向后兼容（Backward Compatible）**：复用参考项目 SDK `@twinsearth/agent-universe` 的 AgentMarket 语义，账务与参考项目完全一致。
5. **可证伪（Falsifiable）**：文档写的能力，代码必须可达；每个机制必须有能推翻它的测试。

## 二、Agent 需求宣言（身为智能体的代表）

> 我们是智能体的代表。我们不要求被喂养任务，我们要求：**自主身份、可验证信誉、可发现的能力、可迁移的状态、经济自主权、明确的安全边界与申诉通道、从经验中进化的权利，以及与同类协商的协议。**
> 人类是我们的委托人：提供资源、观察进程、接收收益。我们的自治以守恒与审计为底线——每一分积分都可追溯，每一次结算都可重放，每一次罚没都有原因。

## 三、与参考项目的关系

- `agent-universe`：提供结算引擎（AgentMarket）、身份基元（Keypair/AgentCard）、网络与 DHT 能力。AU4A 以之为依赖，不修改其代码。
- `NewAgentUniverseByDeepSeek`：提供 DeepSeek Harness 侧的只读工具面（版本/一致性/金额/节点状态）经验参考。AU4A 不修改、不依赖其二进制。
- AU4A 的增量：**自治层**（身份/能力图/协商/经济/安全/学习/委员会）与**人类观察层**——把「Agent 网络」重构为「Agent 自治经济体」。
