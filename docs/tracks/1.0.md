# 轨道 1.0 · Autonomy 自治内核（`au4a-kernel`）

> 中版本代号：**Autonomy 自治内核** ｜ 版本区间：`v1.0.1 → v1.0.10` ｜ crate：`crates/au4a-kernel`
> 一句话：宿主内核只做四件事——**Agent 自主注册、PMB 投递、类型化拒绝、只读观察投影**；
> 其余九条轨道的能力都长在它上面。

## 0. 轨道契约

* **冻结**：`crates/au4a-core/**` 完全只读；`crates/au4a-kernel/src/lib.rs` 的**已有 public 项只增不改签名**。
* **人类只观察**：人类拿到的只有「进度 / 结果 / 收益」三个只读投影；内核里**不存在**以人类为发起者的
  注册、批准、调度、定价、裁决入口。任何「等待人类批准」的分支都是设计错误。
* **确定性**：库代码不读墙钟、不做文件/网络 I/O、不用线程与全局可变状态；时间是 `LogicalClock`。
  同一串输入必须给出同一串输出（注册表指纹 + 场景摘要可逐字节比对）。
* **拒绝分类**：恶意 2 码（`malformed` / `unauthorized`）单次即恶意；竞争 8 码单次只记警告，
  **重复超阈值也只升级到 `Warn`，绝不隔离**——因为竞争而隔离等于因为竞争而误伤。
* **证据分级**：每版自报 `verified` / `cpu-proto` / `unverified`；`unverified` 永远不可结算。
* **测试**：`cargo test -p au4a-kernel`，独立 target 目录 `E:\DS\_forangent\target\au4a-kernel`，
  要求 0 failed、0 warning。

## v1.0.1 宿主内核重构 · status: done

### 目标

把宿主内核从「一张 `BTreeMap<Did, AgentCard>` + 若干散落方法」重构为**可审计、可复现**的宿主：
注册顺序成为语义的一部分，能力查询有倒排索引，内核自己声称的每一条不变式都能被独立断言。

### 交付物

|---|---|
| `crates/au4a-kernel/src/registry.rs` | `AgentRegistry`：注册序 + 能力倒排索引 + `RegistrySnapshot` 指纹；`DuplicateAgent` 仍是调用错误 |

| `crates/au4a-kernel/src/lib.rs` | `Kernel` 内部改用 `AgentRegistry`；新增只读 accessor、`audit()`、轨道级 `self_check()` / `results_json()` / `scenario()` |
| `crates/au4a-kernel/tests/host_kernel.rs` | 9 个只用公开 API 的集成测试（重放、冻结语义、拒绝分类、只读观察） |

## v1.0.2 Agent 自治层骨架 · status: done

### 目标

把「Agent 是主体」落成代码：Agent 自己注册、自己通告能力、自己出价、自己结算、自己决定退避或停手。
**决策输入里没有人类通道，意图集合里没有「等待批准」这种形状**——这不是纪律，是类型结构。

### 交付物

| 文件 | 内容 |
|---|---|
| `crates/au4a-kernel/src/autonomy.rs` | `AutonomyPolicy`（纯函数决策器）、`Intent`/`IntentKind`（8 种自主意图）、`AgentContext`（无人类通道）、`AutonomyLayer`（真驱动内核 + 可重放日志）、`classify_error()` |
| `crates/au4a-kernel/src/lib.rs` | 接线自治层；`scenario()` 新增 `autonomy` 阶段（真的跑两个 turn） |
| `crates/au4a-kernel/tests/autonomy.rs` | 4 个集成测试：无人类步骤的自主闭环、退避 vs 自停、同种子同日志、日志完备性 |

### 接口（新增）

```rust
pub enum IntentKind { Announce, Offer, Progress, Settle, Decline, Defer, Suspend, Idle }
pub enum Intent { Announce, Offer{to,skill,price}, Progress{to,label}, Settle{to,amount,grade},
                  Decline{to,code}, Defer{until}, Suspend, Idle }
pub struct AgentContext { now, available, locked, inbox, last_refusal, defer_until,
                          last_announce_at, halted }          // 无任何人类字段
pub struct AutonomyPolicy { announce_every, min_balance, offer_rate_bp, backoff_ticks }
pub struct AutonomyState { announcements, intents_planned, messages_sent, settlements,
                           last_announce_at, defer_until, halted, journal }
pub struct AutonomyTurn { at, planned, sent, refused }
pub struct AutonomyLayer;
impl AutonomyLayer { new / did / policy / state / journal / join / context / turn }
pub fn classify_error(err: &CoreError) -> RefusalCode;
```

### 验收（真实断言）

1. **无人类步骤**：`AutonomyLayer::join`（自注册）→ `turn` → 广播通告信封入队且验签通过；全程无人工调用。
   结构性断言：`AgentContext` 的 JSON 键集合里不含 `human`/`approv`/`operator`；`IntentKind::ALL`（8 个）名称同样不含。
2. **决策是纯函数**：相同 `(名片, 上下文)` 两次 `plan()` 结果相等；心跳边界（`announce_every`）前只 `Idle`、到点才 `Announce`。
3. **竞争退避、恶意自停**：`settle(unverified)` 被证据闸门拒绝 → `defer_until = at + 3`、`halted == false`、
   且 `escalation_for(..) != Quarantine`；用同种子伪造信封 → 内核记 `unauthorized` → 下一回合 `plan == [Suspend]`、
   `sent == 0`、`halted == true`，且自停是终态（后续竞争码不解除）。
4. **只声明才会做**：收到 `negotiate.offer` 且自身声明了该能力 → `Offer{price = 可用余额 1%（整数基点）}`；
   未声明 → `Decline{unsupported}`；`amount <= 0` 的结算请求 → `Decline{malformed}`。
5. **可重放**：两个内核上同种子的自治层跑 6 个回合，`AutonomyTurn`、`AutonomyState`（含日志）、注册表指纹**全部相等**。
6. **日志完备**：`journal.len() == intents_planned`，每条记录的意图类别都在 `IntentKind::ALL` 内，
   既有动内核的记录（`acted`）也有纯决定的记录。

## v1.0.4 Agent 委员会骨架 · status: done

### 目标

建立自治网络的裁决机构：委员**只能是在册 Agent**（确定性抽签产生），决定必须有法定人数与多数，
而且**隔离动议只对恶意 2 码开放**——竞争行为重复到阈值也只能拿到警告动议。

### 交付物

| 文件 | 内容 |
|---|---|
| `crates/au4a-kernel/src/council.rs` | `CouncilConfig` / `Motion`（内容寻址）/ `MotionKind` / `Ballot` / `Vote` / `Tally` / `Verdict` / `Decision` / `Council`（抽签·动议·投票·计票·决定）/ `CouncilFailure`（8 个具名失败模式）/ `motions_for_kernel()` |
| `crates/au4a-kernel/src/lib.rs` | 接线委员会；`scenario()` 新增 `council` 阶段（真实抽签 + 全员投票 + 计票） |
| `crates/au4a-kernel/tests/council.rs` | 5 个集成测试：抽签只抽在册 Agent、隔离只对恶意、法定人数与多数、非委员/重复投票、空委员会 |

### 接口（新增）

```rust
pub struct CouncilConfig { size, quorum_bps, pass_bps }
pub struct Motion { id, kind, subject, cause, escalation, at }   // id = canonical_hash(内容)
impl Motion { new / compute_id / is_intact / from_escalation }

               submit / vote / tally / decide / decisions / decisions_json / failures }

```

### 验收（真实断言）

1. **委员只能是 Agent**：`sortition` 对同一 `(kernel, epoch, config)` 结果相等；每个委员都 `is_registered`；
   在册不足取全部；空网络 → 0 委员且计票返回 `EmptyCouncil`（`→ degraded`，非恶意）。
2. **竞争不隔离（穷举）**：10 个拒绝码 × 3 个升级级别（`None/Warn/Quarantine`）共 30 种组合，
   只有 `is_misconduct()` 的码能产生 `Quarantine` 动议；竞争码即使上游误传 `Escalation::Quarantine`
   也返回 `None`（有断言）。
3. **真实内核上分类正确**：伪造信封 → `unauthorized` → 1 份隔离动议；证据闸门重复拒绝 5 次 →
   1 份 `Warn` 动议且 `cause = policy_denied`；动议 id 内容自洽（`is_intact`）。
4. **法定人数与多数是整数门槛**：5 人 60% → 法定 3 人；2 人出席 → `NoQuorum` + `Inconclusive`；
   3 赞成 / 2 反对且 `pass_bps=5100` → `Upheld`；全员弃权 → `TieInsufficient`（不产生决定）。
5. **具名失败模式**：非委员投票 → `NonMemberVote`、同人两票 → `DuplicateVote`（二者 `to_refusal_code()`
   均为 `unauthorized`，单次即恶意）；未知动议 → `unsupported`；重复动议 → `conflict`；
   `UnknownMotion/DuplicateMotion/NoQuorum/TieInsufficient/EmptyCouncil → to_refusal_code()` 均**非**恶意码。
6. **决定可复现**：同一输入序列两次运行，`Tally`、`decisions`、`decisions_json()` 指纹全等。
